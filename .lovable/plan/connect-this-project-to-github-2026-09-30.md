## Connect this project to GitHub

There is no GitHub repository linked to this project yet. Right now the code is stored only in Lovable. You do the connection yourself in the editor, and no code changes are needed.

### Steps
1. In the chat box, open the **+** menu at the bottom left.
2. Choose **GitHub**, then **Connect project**.
3. Approve the Lovable GitHub App on GitHub when you're asked.
4. Pick the GitHub account or organisation that should own the repository.
5. Click **Create Repository**.

### What happens next
- Lovable creates a new repository containing all of the site's code.
- Syncing works both ways and happens automatically. Changes made here show up on GitHub, and changes pushed to GitHub show up here.
- The live site, domain and backend stay as they are.
- Your booking records and other database data are not copied to GitHub. You can export those separately from the backend settings if you need them.
